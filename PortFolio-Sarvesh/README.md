# Sarvesh Suyal - Portfolio 🚀

A modern, responsive, and performance-driven portfolio web application showcasing full-stack projects, competitive programming profiles, technical skills, and achievements.

## 🛠️ Built With

- **React 19** - Modern UI library with modular components
- **Vite** - High-performance next-generation frontend tooling
- **React Router v7** - Client-side single page navigation
- **Vanilla CSS / Inline Design System** - Dark-themed glassmorphism aesthetic with zero bulky UI framework dependencies
- **Oxlint** - High-speed static analysis and linting

## 📌 Features

- **About**: Personal introduction, background, core values, and quick highlights.
- **Skills**: Categorized technical proficiencies across Full Stack, Data Science, AI/ML, and Core CS.
- **Projects**: Interactive portfolio showcase with category filtering (AI/ML, Full Stack, Algorithms, Data Science) and direct code links.
- **DSA / CP**: Live problem-solving statistics, rating cards, and competitive coding links (LeetCode, Codeforces, etc.).
- **Achievements**: Academic milestones, coding contest badges, and certifications.
- **Mobile Responsive**: Custom-built adaptive navigation and flex/grid layouts for all device viewports.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sarveshsuyal/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build locally:
   ```bash
   npm run preview
   ```

## 🌐 Deployment

Configured for one-click deployment on [Vercel](https://vercel.com/) with full SPA client-side routing support via `vercel.json`.
